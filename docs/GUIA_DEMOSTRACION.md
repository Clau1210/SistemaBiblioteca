# Guía de demostración

1. Iniciar sesión como administrador.
2. Mostrar el panel y explicar los indicadores.
3. Crear un usuario con rol encargado.
4. Registrar un lector.
5. Registrar una categoría, un autor y una editorial.
6. Registrar un libro y dos ejemplares.
7. Crear un préstamo seleccionando un ejemplar disponible.
8. Comprobar que el ejemplar cambió a prestado.
9. Registrar la devolución.
10. Comprobar que el ejemplar volvió a disponible.
11. Descargar los reportes Excel y PDF.
12. Mostrar las ramas, commits, pruebas y documentación en GitHub.
