# Lista de verificación del Avance 2

## Informe PDF

- Carátula e índice actualizados.
- Resumen y abstract alineados con la implementación.
- Capítulos 1, 2 y 3 completos.
- Requisitos SRS, casos de uso, diagramas, base de datos y prototipos.
- Conclusiones, recomendaciones, bibliografía APA y anexos.
- Evidencia propia del contexto estudiado, si la institución la proporciona.

## Presentación de ocho minutos

- Problema, objetivo y alcance.
- Requisitos y proceso principal.
- Arquitectura, patrones y seguridad.
- Base de datos y diseño de clases.
- Demostración de préstamo y devolución.
- Reportes, pruebas y GitHub.

## Software

- Proyecto comprimido y repositorio GitHub accesible al docente.
- Variables de conexión revisadas.
- Base de datos preparada.
- Pruebas ejecutadas.
- WAR generado y desplegado.
- Datos de demostración diferenciados de los datos reales.

La calificación final depende también de la evidencia, el repositorio remoto y el dominio demostrado durante la sustentación.
